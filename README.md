# Escape the Box

Escape the Box is a 3D platformer game developed in Unity using C#. This project was developed as part of an A2 Computer Science project and showcases core game development skills.

## About

Escape the Box is a 3D platformer where you guide a character through a minimalist, abstract world, utilizing responsive controls to overcome obstacles and progress through levels. The game emphasizes physics-based movement, a clear objective, and an accessible design. This project demonstrates the ability to rapidly learn and apply new technologies and deliver a playable product within a constrained timeline.

## Features

*   **Responsive Movement:** The player can move using WASD keys and jump with the space bar.
*   **Platforming Challenges:** Levels are constructed with platforms that require jumping and careful movement to traverse.
*   **Environmental Hazards:** Cacti act as hazards, causing the player to be knocked back, and triggering a flashing effect.
*   **Checkpoint System:** Red orbs act as checkpoints, allowing players to respawn at the last activated checkpoint upon death.
*   **Gold Collection:** Gold bars can be collected throughout the levels to increase the player's score.
*   **Pause Menu:** The game can be paused using the ESC key, providing options to resume, return to the main menu, or quit.
*   **Main Menu:** A simple main menu allows players to start the game, access settings (not yet implemented), and quit.
*   **UI:** A basic UI displays the player's health (represented by hearts) and collected gold.

## Getting Started

### Prerequisites

*   Unity (version 2022.3.10f1 or later recommended)
*   .NET Framework
*   Visual Studio C++ Redistributable Packages
*   DirectX 9 or higher

### Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/MahdiRazzaque/Escape_the_box
    ```
2. Open the project in Unity.

## Usage

*   Use WASD keys to move the character.
*   Press the space bar to jump.
*   Avoid hazards (cacti).
*   Collect gold bars to increase your score.
*   Reach the end of the level to progress.
*   Press ESC to pause the game.
